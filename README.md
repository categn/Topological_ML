# Topological ML
This is the code repository of the article **"Topological Machine Learning for Financial Crisis Detection: Early Warning Signals from Persistent Homology"**.

## INFO 
The analysis is in **Python** and uses the package **giotto-tda**  for the topological framework.

## Files:
- **TDA_analysis.ipynb**: the notebook with the full analysis and figures from the article
- **utils.py**: a file with utility functions
- **requirements.txt**
